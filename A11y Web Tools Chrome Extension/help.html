A11y Web Tools

Purpose

A11y Web Tools is an extension that helps you create and inspect websites and applications to make them accessible. It was designed primarily for use with the Canvas LMS, but works on any website.

Tool Descriptions

Activate All / Deactivate All

These buttons toggle all primary A11y Web Tools (six tools beneath it) at once. Your preferences are saved and automatically applied when you load a Canvas page.

Image Overlays

Adds overlays around images that display alt text, indicate decorative images, or show a warning when alt text is missing.

Iframe Overlays

Adds overlays around iframes that display attributes such as aria-label, aria-description, and title, or indicate when they are missing. Emoji icons show which attributes a typical screen reader would announce. Red labels indicate attributes that may need to be fixed.

Heading Overlays

Adds overlays that label headings with their level (H1, H2, etc.). This is useful for identifying whether headings are ordered properly.

Table Overlays

Adds overlays only to tables that have potential issues (for example, missing scope attributes, missing header cells, or the use of merged cells). Additional settings can also enable highlighting table header cells for all tables.

Contrast Highlighting

Highlights text that fails WCAG color-contrast requirements. The analysis accounts for text size, text color, and background color. Hovering over the highlighted text shows recommended changes to either the text color or background color to satisfy color contrast requirements. While hovering, Shift + left-click to copy the hex code for the recommended text color or Shift + right-click to copy the hex code for the recommended background color.

Language Highlighting

Highlights text that may require a change to the lang attribute. This uses a combination of a local AI language prediction model and a large dictionary of English words. The tool tries to determine the language of the text and compares it to the semantically declared language. If they don't match, the text is flagged as a potential error. Neither the dictionary nor the AI model are perfect, so false positives can occur.

Count Elements

Provides three counting options that add 1-indexed overlays to tables, iframes, or paragraphs. This makes it easier to find the n-th element when reviewing accessibility reports.

Raw HTML Editor

When enabled, this tool automatically switches the Canvas editor from the graphical editor to the raw HTML view. This setting preserves your preference for the raw HTML editor.

Open Dropdown Menus

When enabled, loading a Canvas page automatically expands dropdown menus so all content is visible for inspection. Note that Canvas sometimes expects only one dropdown to be open at a time, so the resulting layout may appear differently than it would normally.

Color Contrast Inspector

Enables a hover inspector that shows the hex codes for text and background colors. Use right/left click to copy hex codes. The inspector also reports whether the color contrast passes WCAG guidelines, taking font size into account.

Download SLA Files

If you are on a Teamwork page, this tool attempts to download SLA reports using existing filters.

User Settings

Run Enabled Tools on All Pages

When enabled, the main six A11y tools will automatically run (if enabled), regardless of what page is being viewed. Your per-tool preferences are saved.

Enable Numpad + / - Hotkeys for A11y Tools

When enabled, the numpad + key activates all primary a11y tools and the numpad - key deactivates them all.

Enable Alt + ↓ / ↑ to Expand/Collapse Dropdowns

When enabled, using Alt + ↓ expands all Canvas dropdowns and Alt + ↑ collapses them.

Enable Raw HTML Editor Highlights

When enabled, the raw HTML editor in Canvas highlights elements related to accessibility, including:

  • aria-label="..."
  • title="..." or aria-description="..."
  • alt="..."
  • <table> (table tags)
  • <h#>...</h#> (heading tags; darker for larger headings)
  • lang="..."
  • Invisible links

Enable Additional Raw Editor Toolbar

When enabled, the raw HTML editor receives an additional menu that includes a refined search tool (integrates with Ctrl + F), an easier-to-access Save button, and an aria-label fixer. Activating it will prompt you to choose or type an accessible label for each iframe. Finally, enabling this option also adds the ability to save edits with Ctrl + S.

Expand Canvas Edit Pages by Default

When enabled, the editors in Canvas open in a larger view by default. This includes both the graphical editor and the raw HTML editor.

Highlight Table Headers

When enabled, the main a11y table tool will also highlight all <th> header cells, making them easier to identify.

Enable Counting Canvas Modules

When enabled, overlays will be added to count Canvas modules on the Modules page and the Home page (if applicable). Overlays are 1-indexed. Each module overlay also includes a link to open all pages in that module.

Enable Canvas File Paths on Hover

When enabled, hovering over a file on the Canvas Files page shows the file path as a tooltip and adds a link to open the folder that contains the file. This especially helps when using the Canvas file search tool.

Enable Ctrl + Q for H5P Language Replacement

When enabled, this setting allows you to apply the currently chosen language attribute to highlighted text within H5P activities by using Ctrl + Q. Additionally, when you open the language selection menu within H5P activities, it will automatically scroll to the currently chosen language.

Current H5P Language

This setting allows you to choose which language to use for the above setting. Language input is case insensitive and utilizes a partial match. This setting is persistent.

Frequently Asked Questions

What does "a11y" mean?

A11y is the standard abbreviation for "accessibility". The number 11 represents the eleven letters between "a" and "y".

Why aren't the a11y tools automatically running?

By default, the a11y tools only automatically run on Canvas pages. Since some pages on Canvas don't support editing, the tools won't automatically run. This includes pages like Modules, Files, Settings, and similar views. To have the tools automatically run on non-Canvas pages, enable the Automatically Run Tools on All Pages setting and ensure the a11y tools are enabled.

Why doesn't the page update when I change a setting?

Some tools and settings require a page refresh to take effect. If you don't see changes happen, try reloading the page.

Why aren't my a11y tool settings preserved?

Tool settings are only saved on pages that the tools will also automatically run on. If you enable tools on a page where they don't run (such as the Modules page), those preferences won't be saved. When the Run Enabled Tools on All Pages setting is enabled, a11y tool settings will be preserved.

Why isn't the Canvas edit box expanding?

The edit box only expands when there's enough content to benefit from the expansion. If the page content is too small, the extension won't expand the edit box.
